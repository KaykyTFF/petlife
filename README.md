# LifePet

LifePet é um aplicativo web acadêmico focado no monitoramento e cuidado de animais de estimação.

## Tecnologias
- **Vite:** Ambiente de desenvolvimento e build.
- **Tailwind CSS:** Framework de estilos utilitários.
- **JavaScript:** Lógica pura (Vanilla JS).
- **Multi-page Architecture:** Cada página é um arquivo HTML independente.

## Como rodar o projeto
1. Instale as dependências: `npm install`
2. Rode o servidor de desenvolvimento: `npm run dev`
3. Acesse `http://localhost:5173` no seu navegador.

## Estrutura de Pastas
- `pages/`: Contém as páginas do sistema.
- `src/css/`: Estilos globais e componentes.
- `src/js/`: Lógica de negócio e scripts de páginas.
- `src/components/`: Componentes reutilizáveis em JS.
- `public/`: Ativos estáticos como imagens e ícones.
- `docs/`: Documentação técnica do projeto.
